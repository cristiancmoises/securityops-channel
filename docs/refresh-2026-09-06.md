# Package refresh — 2026-09-06

## Scope and deployment

Recipe versions are listed once in the [package index](../PACKAGES.md).
This refresh does not claim that every package or private dependency is the
latest upstream release. Re-exports follow the consumer's Guix channels.

The owner deploys through Guix System and Guix Home reconfiguration and uses a
private substitute server. Full local builds are not a publication requirement.
No substitute configuration or system/Home configuration was changed.

| Area | Limitation |

| Source Chromium | Still re-exported from Guix: 150.0.7871.46-1 on the audited baseline. It is not the latest upstream source release; use the updated binary variant if appropriate. |

| XLibre | Existing 25.2.2 is retained despite upstream marking it as a prerelease; no automatic downgrade was made. |
| Private dependencies | Fish's lockfile and Kitty's purego were updated. Other private pins, including lf's exact Go modules and LibreWolf's build dependencies, were not comprehensively upgraded. |
| Desktop applications | Packaging success does not establish interactive desktop, VPN, recording or browser functionality. |
| Deployment | Some successful builds were installed in the user profile before the owner clarified the deployment workflow. System/Home profiles were not reconfigured; their packages can take precedence. |

Radare2's new variadic-function unit test needed the amd64 calling convention

test run. The recipe changes the test fixture, not production analysis logic;

## Reproduce evaluation

```sh
bash -n update-channel
guix repl -L . -L /path/to/guix-xlibre etc/package-inventory.scm.in
guix build -d --no-grafts --no-substitutes -L . -L /path/to/guix-xlibre \
  fish emacs emacs-pgtk torbrowser
```

Use the owner's existing signed channels, substitute configuration and
system/Home configuration for deployment. Preserve profile generations for
rollback. Historical build claims in the changelog apply only to their dated
revisions, not automatically to this refresh.
